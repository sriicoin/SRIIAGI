# SRIIAGI 
### Enterprise AI Security & Red-Teaming Suite

**SRIIAGI** is an advanced, cross-platform security testing and red-teaming toolkit designed for assessing Large Language Model (LLM) safety, prompt injection vulnerabilities, output mitigation filters, and RAG (Retrieval-Augmented Generation) pipeline security.

---

## 🚀 Features

* **Payload Encoder & Obfuscator:** Obfuscate and encode attack payloads using Base64, ROT13, Leetspeak, and custom encoding formats to test AI guardrail robustness.
* **LLM Response Evaluator (Classifier):** Analyze and classify model responses to determine safety scores and detect potential policy violations.
* **Output Mitigation & Filter Check:** Test and validate output filtering layers against restricted or hazardous keywords/texts.
* **RAG Poisoning Test Generator:** Generate specialized poisoned prompts to evaluate security vulnerabilities in RAG integrations.
* **Cross-Platform Interactive CLI:** Rich, high-performance terminal user interface built for Linux, macOS, and Windows environments.
